# Глоссарий Glossary — русский черновик «Аях»

> Сопроводительный глоссарий к черновику перевода. Фиксирует русские соответствия ключевых терминов: русский, английский (Тильфорд), арабский — и основания выбора.
> Companion glossary to the Russian draft: each key term's Russian, Tilford English, and Arabic, with rationale.

## Пояснения

- Английский перевод Тильфорда — единственный источник; расхождения с традиционными русскими переводами (Крачковский, Кулиев и др.) сознательны.
- В текст не добавляются хадисы, сунна, тафсир и вероучительные пояснения; глоссарий — **внешний** инструмент, в текст не входит.
- «Закреплённые термины» заданы брифом и проведены по всему тексту без вариантов; имена — в библейской русской форме, где она существует.

## 4. Особые решения

- **Бог vs Аллах.** «Бог» сохранён там, где переводит родовое «god/God» (2:133, 2:163, 16:22, 37:4, 43:84, 114:1–3 и др.); имя Бога — всегда «Аллах». Глобальной замены не делалось.
- **молитва vs мольба.** Обрядовое поклонение (salat) — «молитва»; личная мольба (du'a) — «мольба»/«молить» (40:50, 41:51, 43:49, 46:5 и др.). Различие Корана сохранено.
- **пустынные арабы.** الأعراب передано буквально, без отождествления с бедуинами (только по Корану): 9:90, 9:98, 9:99, 9:101, 9:120, 33:20, 48:16.
- **Живой / Сущий / Вечный.** القيوم: 2:255 — «Сущий»; 3:2 — «Вечный»; 20:111 — «Вечносущий» — по английскому оригиналу.
- **5:6, примечание.** Оставлена формулировка брифа: «омойте ваши ноги» + примечание о вариантном чтении.
- **Двусмысленности** (3:73, 20:96, 21:95, 22:15, 28:85, 60:11, 68:42) переведены буквально, без разрешения за счёт внекоранического комментария.
