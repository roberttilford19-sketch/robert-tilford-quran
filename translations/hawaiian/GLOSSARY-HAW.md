Consolidated 2026-11-22 from the NAMES USED and TERMS sections of work/flags_01–17.md
(canonical set; flags_14_63-75_backup.md excluded — it belongs to the superseded
duplicate draft of Surahs 63–75, see BUILD-REPORT-HAW-2026-11-22.md).

## Locked terminology (WORKER-BRIEF.md)

- Allah → **Allah**
- ar-Raḥmān → **ka Mea Lokomaikaʻi**
- ar-Raḥīm → **ka Mea Aloha**
- Rabb (Lord) → **ka Haku**
- ilāh (generic god / the true God in context) → **ke Akua**
- Basmalah → *Ma ka inoa o Allah, ka Mea Lokomaikaʻi, ka Mea Aloha.*
- salat (prayer) → **ka pule**
- Satan → **Sātana**; angel → **ka ʻānela**; jinn → **ka jinn**
- believer → **ka mea manaʻoʻiʻo** (plural: ka poʻe manaʻoʻiʻo)
- disbeliever → **ka mea hōʻole manaʻoʻiʻo** (plural: ka poʻe hōʻole manaʻoʻiʻo)
- Hell → **gehena**; the Garden/Paradise → **ka pāradiso**
- fasting → **ka hoʻokē ʻai**; the poor-due → **ka zakat** (bare term, no percentage, no gloss)
- prostration — recommended → *[e kūlou — paipai ʻia]*
- prostration — obligatory → *[e kūlou — koi ʻia]*
- Meccan → **Mekana**; Medinan → **Medina**; verses (header) → **paukū**
