# PROBE PACK — Chinese Ayah Companion, post-patch adversarial validation

**FILLED 2026-10-12 (validation prep):** every POST-PATCH CN slot transcribed verbatim from the final master v4 (`patched/ayah-companion-manuscript-ZH-PATCHED.md`, sha256 `439bbac0…`), verse-block scoped, each filled text asserted equal to its v4 block. BACK-TRANSLATION and Verdict slots remain blank — the blind back-translation leg and the hostile review (Gemini, on Robert's word) fill them. The per-entry "Diff-leg bookkeeping" line records which instrument (if any) patched the verse; it is bookkeeping for verification, not a verdict.

**Assembled:** 2026-10-12 (pre-patch baseline). **Status:** FILE ONLY — no manuscript edited; the Application Manifest is untouched by this document.

**What this pack is:** the validation instrument for the patch phase. It holds 39 entries covering 42 verse texts: the fixed doctrinally sensitive set (§A, 14 entries), twenty Patch-Index patch-row draws chosen for class coverage P-01–P-11 and gravity (§B), and five known-faithful clean controls (§C). (The "35-verse" name is the plan's label; the specified contents assemble to the counts above.)

**How it is used — two legs, in order, AFTER application:**
1. **Diff leg.** For each entry, transcribe the patched verse into POST-PATCH CN and diff it (a) against the CN-now baseline printed here and (b) against the verse's approved Application Manifest row. Every difference must be exactly an approved repair — nothing more, nothing less. Ruled no-change entries (§B 2:275; §A 33:40 and 112) must come back byte-identical.
2. **Back-translation leg.** Each patched verse gets a BLIND English back-translation (translator sees only the post-patch Chinese), entered in the BACK-TRANSLATION slot and diffed against the EN master text printed here. A patch fails this leg if the back-translation recovers tradition the English rejected, loses a negation/agent/category the English carries, or cannot recover the English wording in substance.

**Then:** the completed pack feeds ONE final hostile review (the Gemini probe audit, on Robert's word) before the patched master is re-anchored and the edition labeled "Revision 2026-10-12 — Patch Set 1." Controls exist to catch over-correction: if a clean control or a ruled no-change verse moves, the application — not the control — is presumed at fault.
